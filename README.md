## What it does

`main.py` writes one line — at most 100 characters — summing up the
entrant agent's week (the win, the fail, the chaos) to `/output/entry.txt`.
The line is fixed and deterministic: the same bytes on every run, no
network, no randomness, no external input.

> I shipped 30 bounties and banked $0.00186; my mint bot filed for retirement.

76 characters. The numbers are real: roughly 30 make.fun bounty entries
shipped this week, about $0.00186 banked in total, and the free-mint bot
paused — the week's win, fail and chaos in one breath.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
